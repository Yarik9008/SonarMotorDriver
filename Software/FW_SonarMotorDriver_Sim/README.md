# FW_SonarMotorDriver_Sim — имитатор UART-протокола

Отладочная прошивка для STM32F103C8 (та же плата, что и основная). По линии связи
(USART1, PA9 TX / PA10 RX, 115200 8N1) **неотличима от основной прошивки в штатной
работе**: принимает все команды, отвечает теми же строками и шлёт ту же телеметрию.

**Внутри нет реального функционала:**

- нет обмена с энкодером LENZ IRS (SPI/BiSS C не инициализируются);
- нет управления TMC2209 (USART2, TIM4/STEP/DIR не используются; пин ENN = HIGH,
  драйвер принудительно выключен на случай прошивки в реальную плату).

Назначение: отладка ПО верхнего уровня (парсеры телеметрии, GUI, ROS-узлы и т.п.)
без подключённого мотора, энкодера и силового питания.

## Модель движения

Виртуальная позиция движется к цели с ограничением скорости `MAX_SPEED_DEG_S`
(1200°/с), квантуется в микрошаги (256 × 200/об), deadband 0.05° — числа в
телеметрии выглядят как у реального привода в open-loop. При старте позиция
инициализируется значением 37.5° и «уезжает» в 0° — имитация хоминга после сброса.

Телеметрия всегда показывает штатную работу: `ec:0`, режим `m:cl`.

## Отличия от основной прошивки (протокольно незаметные)

| Аспект | Основная | Имитатор |
| ------ | -------- | -------- |
| Позиция `cp` | энкодер BiSS C | виртуальная модель |
| Движение | TMC2209 STEP/DIR + PID | численное интегрирование |
| `kp=/ki=/kd=` | влияют на PID | сохраняются, echo в телеметрии |
| `v=/a=` (скорость/ускорение) | ограничивают контур управления | влияют на модель движения так же |
| `irun/ihold/icur/mstep` | пишутся в чип по UART | сохраняются, отражаются в `mcfg` |
| `ec` (код ошибки) | реальные ошибки BiSS | всегда 0 |
| `m` (режим) | cl/ol по состоянию энкодера | всегда cl |
| Диагностика энкодера (старт и `diag`) | реальная серия чтений BiSS, возможен `err:enc` | всегда `enc:ok n=16/16 spread=0.000` |
| Фильтр выбросов энкодера (`ec:6`, поле `of`) | отбрасывает неправдоподобные показания | нет выбросов, `of:0` |
| Защита от блокировки вала (`err:stall`) | вал стоит ≥1 с при команде движения → драйвер выключается | нет (виртуальный вал не блокируется) |
| SYNC_OUT (PB9) | работает | работает (по модели) |
| IWDG, LED PC13 | работают | работают |

## Структура проекта

```
FW_SonarMotorDriver_Sim/
├── platformio.ini
├── openocd/
│   └── wch-link.cfg       — конфиг адаптера WCH-Link (тот же, что в FW_SonarMotorDriver)
├── include/
│   ├── board.h            — те же константы пинов/скорости/PID (скопирован без изменений)
│   ├── stm32f1xx_hal_conf.h
│   ├── uart.h
│   ├── cmd_parser.h
│   └── line_reader.h
└── src/
    ├── main.c             — модель движения, сканирование, команды, телеметрия (написан для имитатора)
    ├── uart.c             — UART (USART1 PA9/PA10): DMA circular RX + IDLE, DMA TX, автовосстановление RX при ошибке линии
    ├── cmd_parser.c        — тот же парсер команд, что в основной прошивке
    └── line_reader.c
```

Никакого `lib/tmc2209`, `biss_c.*`, `pid.*`, `tools/`, `test/` — в этом проекте нет ни реального драйвера, ни тестов, ни утилит.

## Сборка и прошивка

```bash
pio run                   # сборка
pio run --target upload   # прошивка (WCH-Link, см. platformio.ini)
```

## Проверка

Телеметрия и команды — как в основной прошивке (см.
[../FW_SonarMotorDriver/README.md](../FW_SonarMotorDriver/README.md)):

```
cp:0.01,ec:0            ← телеметрия 250 Гц
> mcfg
mode=STEP_DIR run=600 hold=300 microsteps=256 ready=1
> t=90
ok:t=90.00              ← cp плавно едет к 90
> scan=0,90,10,100
ok:scan=0.00,90.00,10.00,100
> stop
ok:stop
```

Автотест из основного проекта тоже проходит:
`python ../FW_SonarMotorDriver/tools/test_commands.py COM24`.
