# Test_TMC2208 — Тестовая прошивка TMC2209 + STM32F446RET6

Управление шаговым двигателем через драйвер TMC2209 с интерфейсом команд
по USB CDC (виртуальный COM-порт).

## Аппаратная часть

### MCU

**STM32F446RET6** (LQFP-64), HSE 8 МГц, SYSCLK 168 МГц.

### Подключение TMC2209

```
STM32F446          TMC2209
──────────         ───────
PA2 (USART2_TX) ──┬── PDN_UART    (через R 1 кОм от PA2)
PA3 (USART2_RX) ──┘                (напрямую к PDN_UART)
PB8              ───── STEP
PB7              ───── DIR
PB6              ───── ENN         (LOW = вкл, HIGH = выкл)
```

### Схема подключения UART (single-wire)

TMC2209 использует **однопроводной UART** на пине PDN_UART.
MCU подключается двумя линиями (TX + RX) к одному пину TMC2209:

```
         1 кОм
PA2 (TX) ──[===]──┬── PDN_UART (TMC2209)
                  │
PA3 (RX) ─────────┘
```

Резистор 1 кОм на TX предотвращает конфликт при одновременной передаче
(MCU TX + TMC2209 ответ на той же линии). RX подключен напрямую.

### Адресация TMC2209

Адрес задаётся пинами MS1/MS2 на TMC2209:

| MS1 | MS2 | Адрес |
|-----|-----|-------|
| GND | GND | 0     |
| VCC | GND | 1     |
| GND | VCC | 2     |
| VCC | VCC | 3     |

В прошивке: `TMC2209_UART_ADDR = 0` (MS1=GND, MS2=GND).

### Питание TMC2209

```
         TMC2209
         ┌──────────┐
VM ──────┤ VS       │   Питание мотора: 4.75–29 В
         │          │
VCC_IO ──┤ VCC_IO   │   Логика: 3.3 В (от STM32)
         │          │
GND ─────┤ GND      │
         │          │
    ┌────┤ OA1  OB1 ├────┐
    │    │          │    │   Обмотки шагового
  Motor  │ OA2  OB2 │  Motor  двигателя (A и B)
  Coil A └──────────┘  Coil B
```

**Обязательные конденсаторы:**
- **100 мкФ** (электролит, low ESR) между VS и GND — как можно ближе к TMC2209
- **100 нФ** керамика между VS и GND — рядом с микросхемой
- **100 нФ** керамика между VCC_IO и GND
- **2.2 мкФ** между 5VOUT и GND (выход внутреннего регулятора)

### Токоизмерительные резисторы (Rsense)

Прошивка настроена на **Rsense = 0.11 Ом** (внешние резисторы).
Устанавливаются между выводами BRA/GND и BRB/GND.

Ток задаётся в `board.h`:
- `TMC2209_IRUN_MA = 800` — ток при движении (мА)
- `TMC2209_IHOLD_MA = 400` — ток удержания (мА)

### USB

```
STM32F446          USB разъём
──────────         ──────────
PA11 (D-)  ─────── D-
PA12 (D+)  ─────── D+
GND        ─────── GND
```

USB OTG FS (Full Speed), виртуальный COM-порт (CDC).

### Сводная таблица пинов STM32F446

| Пин  | Функция          | Периферия      | Примечание                      |
|------|------------------|----------------|---------------------------------|
| PA2  | USART2_TX (AF7)  | TMC2209 UART   | Через 1 кОм к PDN_UART         |
| PA3  | USART2_RX (AF7)  | TMC2209 UART   | Напрямую к PDN_UART             |
| PA11 | USB OTG FS D-    | USB CDC        |                                 |
| PA12 | USB OTG FS D+    | USB CDC        |                                 |
| PB6  | GPIO OUT         | TMC2209 ENN    | LOW = драйвер вкл              |
| PB7  | GPIO OUT         | TMC2209 DIR    | Направление вращения            |
| PB8  | GPIO OUT / TIM4_CH3 (AF2) | TMC2209 STEP | GPIO в UART-режиме, PWM в SD-режиме |

### Тактирование

```
HSE 8 МГц → PLL (M=4, N=168, P=2, Q=7, R=2)
  SYSCLK  = 168 МГц
  AHB     = 168 МГц
  APB1    = 42 МГц  (таймеры APB1 = 84 МГц)
  APB2    = 84 МГц
  USB CLK = 48 МГц  (PLL48CLK = PLLQ)
```

## Прошивка

### Сборка

Требуется [PlatformIO](https://platformio.org/). Сборка:

```
pio run
```

### Загрузка (DFU)

1. Перевести MCU в режим DFU: BOOT0 = 1, нажать Reset
2. Загрузить:

```
pio run -t upload
```

3. Вернуть BOOT0 = 0, нажать Reset

### Режимы управления

**UART (по умолчанию)** — TMC2209 использует встроенный генератор шагов.
Скорость задаётся через регистр VACTUAL. Пины STEP/DIR игнорируются.
Знак значения определяет направление.

**STEP/DIR** — MCU генерирует импульсы на пине STEP через TIM4 (PWM).
Пин DIR задаёт направление. VACTUAL = 0, TMC2209 слушает внешние импульсы.

### Команды (USB CDC терминал, 115200 8N1)

| Cmd    | Описание                                              |
|--------|-------------------------------------------------------|
| `?`    | Список команд                                         |
| `i`    | Повторная инициализация TMC2209                       |
| `m<N>` | Движение: UART — VACTUAL, STEP/DIR — шагов/сек (±)   |
| `s`    | Стоп                                                  |
| `e`    | Включить драйвер (ENN=LOW)                            |
| `d`    | Выключить драйвер (ENN=HIGH)                          |
| `p`    | Режим STEP/DIR                                        |
| `u`    | Режим UART                                            |
| `st`   | Чтение DRV_STATUS                                     |
| `v`    | Версия IC (ожидается 0x21)                            |

### Примеры

```
?              → список команд
v              → IC=0x21 OK
m500           → UA=500     (UART: VACTUAL=500)
s              → stop
p              → mode:SD    (переключить в STEP/DIR)
m1000          → SD=1000    (1000 шагов/сек вперёд)
m-500          → SD=-500    (500 шагов/сек назад)
s              → stop
u              → mode:UA    (вернуться в UART)
st             → DRV=0x... [UA]
```
