# SonarMotorDriver

Комплексный проект драйвера моторов с поддержкой индуктивного энкодера LENZ IRS по интерфейсу BiSS C. Включает прошивку для STM32F103C8 и проект печатной платы.

## Структура проекта

| Каталог | Описание |
|---------|----------|
| **FW_SonarMotorDriver/** | Прошивка для STM32F103C8 — считывание энкодера по BiSS C, вывод данных по USB CDC |
| **PCB_SonarMotorDriver/** | Проект печатной платы (Altium) — схема и разводка |

## Основные возможности

- **Энкодер LENZ IRS** — абсолютная угловая позиция (17–18 бит) по протоколу BiSS C
- **RS422** — интерфейс MA/SLO энкодера через трансиверы (THVD1452)
- **USB CDC** — передача данных на ПК через виртуальный COM-порт
- **TMC2208** — шаговый драйвер моторов (на плате)

## Быстрый старт

### Сборка прошивки

```bash
cd FW_SonarMotorDriver
pio run
```

### Прошивка

```bash
pio run --target upload
```

Подробная документация по прошивке, подключению энкодера и устранению неисправностей — в [FW_SonarMotorDriver/README.md](FW_SonarMotorDriver/README.md).

## Требования

- **PlatformIO** — для сборки прошивки
- **Altium Designer** — для работы с PCB (файлы .PrjPcb, .SchDoc, .PcbDoc)
