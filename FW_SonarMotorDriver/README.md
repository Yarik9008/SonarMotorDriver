# FW_SonarMotorDriver — Closed-Loop Stepper + LENZ IRS

Прошивка для STM32F103C8 (Blue Pill): позиционное управление шаговым двигателем
через **TMC2208** с обратной связью от абсолютного энкодера **LENZ IRS** (BiSS C).
При потере энкодера — автоматический переход в **open-loop**. Настройка и мониторинг — через **USB CDC**.

## Архитектура

```
                        ┌────────────────────────────────────────────────────────┐
                        │                     Main Loop (1 кГц)                  │
                        │                                                        │
 ┌──────────┐  SPI1     │  ┌──────────┐    ┌─────────┐    ┌──────────────────┐   │
 │  LENZ    │  (BiSS C) │  │ BiSS C   │    │   PID   │    │    TMC2208       │   │
 │  IRS     ├──────────►│  │ Encoder  ├───►│ (cl)    ├───►│  STEP/DIR/ENN    │   │
 │ Encoder  │  RS422    │  │ Driver   │pos │ или     │step│  (Stepper)       │   │
 └──────────┘  THVD1452 │  └──────────┘    │ speed   │    └───────┬──────────┘   │
                        │       │          │ (ol)    │            │ UART (PA2)   │
                        │  enc_ok?         └────┬────┘            ▼              │
                        │  ┌───────────────────┴──────────┐ ┌──────────────┐     │
                        │  │ cl: PID(target-pos)          │ │ IHOLD_IRUN   │     │
                        │  │ ol: g_ol_speed шагов/с       │ │ DRV_STATUS   │     │
                        │  └──────────────────────────────┘ └──────────────┘     │
                        │                                                        │
 ┌──────────┐  USB CDC  │  ┌─────────┐   target, speed, kp/ki/kd, op             │
 │    ПК    │◄─────────►│  │ Cmd     ├───► Телеметрия: cp,tp,pe,m,ec   │
 │          │           │  │ Parser  │     → USB TX                              │
 └──────────┘           │  └─────────┘                                           │
                        └────────────────────────────────────────────────────────┘
```

### Режимы управления


| Режим                | Условие                     | Поведение                                              |
| -------------------- | --------------------------- | ------------------------------------------------------ |
| **cl** (closed-loop) | Энкодер отвечает            | PID по ошибке target − position                        |
| **ol** (open-loop)   | Энкодер не отвечает ≥500 мс | S-кривая: плавный разгон/торможение со скоростью `s=N` |


Переключение автоматическое:

- **cl → ol:** после `ENCODER_FAIL_MS` (500 мс) без ответа энкодера.
- **ol → cl:** при первом успешном ответе, интеграл PID сбрасывается.

### Контур (1 кГц)

1. **TIM2** — флаг UIF каждые 1 мс.
2. **BiSS C** — чтение позиции через SPI1 + THVD1452.
3. **Режим** — счётчик сбоев: ≥500 мс без ответа → ol; при ответе → cl.
4. **cl:** PID → шаги (ограничение ±50/мс).
5. **ol:** S-curve — плавный разгон/торможение до `g_ol_speed` шагов/с.
6. **Stepper** — STEP/DIR на TMC2208.

### Приоритеты прерываний


| Приоритет | Источник | Назначение                 |
| --------- | -------- | -------------------------- |
| 5         | USB LP   | Обработка USB-пакетов      |
| 15        | SysTick  | HAL_Delay(), HAL_GetTick() |

### USB на Blue Pill

- PA12 (USB DP) требует **подтягивающего резистора 1.5 кОм к 3.3 В**.
- Устройство определяется как COM-порт (VID `0x0483`, PID `0x5740`).

## Использование

### Подключение

1. Энкодер LENZ IRS → THVD1452 → PA5/PA6, PB0/PB1.
2. TMC2208: STEP→PB6, DIR→PB7, ENN→PB8.
3. Питание энкодера 5–12 В, питание драйвера.
4. USB → ПК, открыть COM-порт.

### Телеметрия

Периодический вывод (по умолчанию 100 мс). Все позиции — в градусах (0–360):

```
cp:179.82,tp:180.00,pe:0.18,m:cl,ec:0
cp:90.12,tp:180.00,pe:89.88,m:ol,ec:2
```


| Поле | Описание                                                     |
| ---- | ------------------------------------------------------------ |
| `cp` | Current Position — текущая позиция энкодера, градусы (0–360) |
| `tp` | Target Position — целевая позиция, градусы                   |
| `pe` | Position Error — ошибка позиционирования (tp − cp), градусы  |
| `m`  | Mode — режим: `cl` closed-loop, `ol` open-loop               |
| `ec` | Error Code — код ошибки энкодера (0 = OK, 1–5 см. таблицу)   |


**Коды ec:**


| ec  | Код          | Описание                                                                                                                                                                                                           |
| --- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 0   | OK           | Нет ошибок. Энкодер отвечает корректно.                                                                                                                                                                            |
| 1   | BiSS CRC     | Контрольная сумма CRC6 в кадре BiSS не совпала с вычисленной. Данные повреждены при передаче. Частые причины: помехи в кабеле MA/SLO, длинный кабель без терминации, плохой контакт.                               |
| 2   | BiSS NO_RESP | Энкодер не ответил на опрос. На линии SLO не появился ожидаемый ACK или не хватило бит для чтения позиции. Проверить: питание энкодера (5–12 В), трансивер THVD1452, распайку PA5/PA6/PB0/PB1, целостность кабеля. |
| 3   | BiSS SENSOR  | Бит Error в кадре BiSS = 0. Энкодер сам сообщает о невалидности данных (внутренняя ошибка датчика, инициализация, сбой питания).                                                                                   |
| 4   | BiSS WARN    | Бит Warning в кадре BiSS = 0. Энкодер передал предупреждение о качестве данных. В текущей логике такие данные считаются пригодными (enc_ok), код 4 встречается редко.                                              |
| 5   | BiSS SPI     | Ошибка обмена по SPI (HAL_SPI_TransmitReceive != HAL_OK). Проблема на уровне контроллера: SPI не инициализирован, MISO не подключён, конфликт пинов.                                                               |


### Команды USB


| Команда   | Действие                       | Ответ          |
| --------- | ------------------------------ | -------------- |
| `en`      | Включить драйвер               | `ok:en`        |
| `dis`     | Выключить                      | `ok:dis`       |

## Конфигурация

`include/board.h`:

```c
#define POLL_INTERVAL_MS        1U       // 1 мс (1 кГц)
#define ENCODER_RESOLUTION_BITS 17U      // 17 или 18
#define ENCODER_COUNTS_REV      131072U  // 2^17
#define ENCODER_FAIL_MS         500U     // 500 мс без ответа → open-loop
#define TMC2208_MICROSTEPS      16U      // 1, 2, 4, 8, 16, 32, 64, 128, 256
#define MAX_STEPS_PER_POLL      50U      // Ограничение скорости PID
#define OL_SCURVE_RAMP_MS       200U     // Время разгона/торможения S-кривой (мс)
#define OUTPUT_PERIOD_MS_DEFAULT 100U    // Период телеметрии (мс)
```

При старте: драйвер включён. Микрошаг и ток задаются аппаратно (пины MS1/MS2, Rsense).

### Частота опроса


| POLL_INTERVAL_MS | Частота |
| ---------------- | ------- |
| 1                | 1 кГц   |
| 2                | 500 Гц  |
| 10               | 100 Гц  |
| 100              | 10 Гц   |


### Разрешение энкодера

- **17** — IRS-I34, IRS-I50, IRS-I60
- **18** — IRS-I70, IRS-I80, IRS-I90

## API модулей

### BiSS C

```c
BiSS_Config cfg = { .spi_instance = SPI1, .resolution_bits = 17, ... };
BiSS_Init(&cfg);
BiSS_Status st = BiSS_Read(&rd);  // rd.position, rd.angle_deg
```

### Stepper

```c
Stepper_Init();
Stepper_SetEnable(1);   // Включить (ENN = LOW)
Stepper_Steps(10);     // 10 шагов CW
```

### PID

```c
PID_SetLimits(&pid, -50.0f, 50.0f);
float steps = PID_Update(&pid, error, dt);
PID_Reset(&pid);
```

## Протокол BiSS C

Синхронный протокол: ведущий генерирует MA, ведомый отвечает на SLO.

### Структура кадра

```
│◄─ ACK (4 такта) ─►│ Start │ CDS │◄── SCD (32 бита) ──────────────────►│
│  1  1  1  1        │   0   │  1  │ P23…P0 │ E │ W │ CRC6               │
```


| Поле     | Размер  | Описание                 |
| -------- | ------- | ------------------------ |
| Position | 24 бита | Абсолютная позиция (MSB) |
| Error    | 1 бит   | 1 = OK, 0 = ошибка       |
| Warning  | 1 бит   | 1 = OK, 0 = зазор        |
| CRC6     | 6 бит   | x^6+x^1+x^0              |


### Параметры


| Параметр           | Значение              |
| ------------------ | --------------------- |
| Частота MA         | 0.1 – 5 МГц           |
| Физический уровень | RS422, 5 В            |
| Время готовности   | 50 мс после включения |

## Устранение неисправностей


| Симптом                | Причина                       | Решение                              |
| ---------------------- | ----------------------------- | ------------------------------------ |
| COM-порт не появляется | Нет 1.5 кОм на PA12           | Припаять 1.5 кОм PA12–3.3 В          |
| `ec:2`                 | Энкодер не отвечает           | Проверить THVD1452, питание энкодера |
| `ec:1`                 | CRC — помехи                  | Терминация, укоротить кабель         |
| `ec:3`                 | Бит Error = 0                 | Данные невалидны                     |
| Мотор не двигается     | Драйвер выключен              | Команда `en`                         |
| LED не мигает          | Зависание                     | Отладчик                             |
| Пропуски в терминале   | USB не успевает               | Увеличить `op`                       |
