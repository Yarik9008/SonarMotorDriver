# -FW_SonarMotorDriver — LENZ IRS Encoder Reader

Прошивка для STM32F103C8 (Blue Pill), которая считывает абсолютную угловую позицию
с индуктивного энкодера **LENZ IRS** по интерфейсу **BiSS C** и передаёт данные
на ПК через **USB CDC** (виртуальный COM-порт).

## Архитектура

Прошивка построена на **неблокирующей архитектуре** с опросом по таймеру:

```
  TIM2 (500 Гц)          Main Loop              USB CDC
  ┌───────────┐      ┌─────────────────┐      ┌──────────┐
  │ Аппаратный├─────►│ Опрос флага UIF ├─────►│ Transmit │──► ПК
  │ отсчёт 2мс│ flag │ BiSS C → Format │ buf  │ (COM)    │
  └───────────┘      └─────────────────┘      └──────────┘
```

- **TIM2** аппаратно отсчитывает 2 мс (500 Гц).
- **Главный цикл** опрашивает флаг переполнения таймера (`TIM_FLAG_UPDATE`).
- При переполнении: чтение энкодера по SPI, форматирование, отправка в кольцевой буфер.
- **USB_CDC_Task()** непрерывно опустошает буфер и шлёт данные по USB.
- **LED** мигает ~1 Гц (heartbeat), независимо от частоты опроса.
- **Статистика** ошибок накапливается в массиве `g_stats[]` (доступна через отладчик).

## Аппаратная часть

### Назначение выводов STM32


| Вывод STM32 | Функция       | Назначение                            |
| ----------- | ------------- | ------------------------------------- |
| PA5         | SPI1_SCK      | Тактовый сигнал MA → THVD1452 D       |
| PA6         | SPI1_MISO     | Данные SLO ← THVD1452 R               |
| PB0         | GPIO_OUT (DE) | Driver Enable THVD1452 (active HIGH)  |
| PB1         | GPIO_OUT (RE) | Receiver Enable THVD1452 (active LOW) |
| PA11        | USB_DM        | USB Data Minus                        |
| PA12        | USB_DP        | USB Data Plus                         |
| PC13        | GPIO_OUT      | Светодиод (heartbeat ~1 Гц)           |


### Назначение выводов энкодера


| Пин | Функция | Цвет провода |
| --- | ------- | ------------ |
| 1   | Vcc     | Красный      |
| 2   | GND     | Чёрный       |
| 3   | MA+     | Жёлтый       |
| 4   | MA−     | Зелёный      |
| 5   | SLO+    | Синий        |
| 6   | SLO−    | Белый        |


Разъём: Amphenol FCI 10114830-11106LF.
Ответный разъём (в комплект не входит): 10114826-00006LF + 10114827-002LF.

### Схема подключения

Линии MA и SLO — дифференциальные пары **RS422 (5 В)**. Напрямую подключать
к STM32 нельзя. Используется полнодуплексный трансивер **THVD1452** (TI),
который обеспечивает одновременную передачу тактового сигнала MA и приём данных SLO.

```
  STM32F103          THVD1452                  Энкодер LENZ IRS
 ┌──────────┐      ┌──────────┐      ┌──────────────────────────┐
 │      PA5 ├─────►│ D      Y ├─────►│ MA+  (pin 3, жёлтый)    │
 │ (SPI_SCK)│      │       Z ├─────►│ MA−  (pin 4, зелёный)   │
 │          │      │          │      │                          │
 │      PA6 │◄─────┤ R      A │◄─────┤ SLO+ (pin 5, синий)    │
 │(SPI_MISO)│      │       B │◄─────┤ SLO− (pin 6, белый)    │
 │          │      │          │      │                          │
 │      PB0 ├─────►│ DE       │      │                          │
 │      PB1 ├─────►│ RE       │      │                          │
 │          │      │          │      │                          │
 │      GND ├──────┤ GND      ├──────┤ GND  (pin 2, чёрный)   │
 │      3V3 ├──────┤ VCC      │      │ Vcc  (pin 1, красный)  │◄── 5..12 В
 └──────────┘      └──────────┘      └──────────────────────────┘
```

Управление трансивером:

- **DE = HIGH** (PB0) — драйвер включён, тактовый сигнал MA идёт на шину Y/Z
- **RE = LOW**  (PB1) — приёмник включён, данные SLO с шины A/B поступают на R

Оба пина устанавливаются автоматически при вызове `BiSS_Init()`.

> **Внимание**: питание энкодера 4.6–12 В, ток потребления до 110 мА.
> Питание THVD1452 — 3.3 В от STM32 (допустимо 3.0–5.5 В).

### USB на Blue Pill

- PA12 (USB DP) требует **подтягивающего резистора 1,5 кОм к 3,3 В**.
На некоторых платах Blue Pill он уже установлен, на других — нет.
- После подключения USB устройство определяется как COM-порт
(VID `0x0483`, PID `0x5740`).

| Домен     | Частота            |
| --------- | ------------------ |
| SYSCLK    | 48 МГц             |
| AHB       | 48 МГц             |

## Использование

1. Подключите энкодер через THVD1452 к PA5/PA6 (SPI) и PB0/PB1 (DE/RE).
2. Подайте питание на энкодер (5–12 В).
3. Подключите плату по USB к ПК.
4. Откройте COM-порт (115200 бод не критично — это USB CDC).

Выходные данные в терминале (500 Гц):

```
POS: 65412  ANGLE: 179.824 deg  (raw24: 0x7FE300)
POS: 65413  ANGLE: 179.827 deg  (raw24: 0x7FE380)
POS: 65410  ANGLE: 179.819 deg  (raw24: 0x7FE100)
```

При ошибке (с текстовой мнемоникой статуса):

```
ERR:CRC      E=1 W=1  raw=0x000000  SPI[...]   — CRC не совпала
ERR:NO_RESP  E=0 W=0  raw=0x000000  SPI[...]   — нет ответа от энкодера
ERR:SENSOR   E=0 W=1  raw=0x123456  SPI[...]   — бит Error = 0
ERR:SPI      E=0 W=0  raw=0x000000  SPI[...]   — ошибка HAL SPI
```

При Warning (данные валидны, но есть проблема):

```
POS: 65412  ANGLE: 179.824 deg  (raw24: 0x7FE300)  [W]
```

## Конфигурация

Все аппаратные параметры сосредоточены в `include/board.h`:

```c
#define POLL_INTERVAL_MS        2U      /* Период опроса: 2 мс (500 Гц) */
#define ENCODER_RESOLUTION_BITS 17U     /* 17 для IRS-I34/I50/I60; 18 для I70/I80/I90 */
#define ENCODER_STARTUP_MS      50U     /* Время готовности после подачи питания */
```

### Изменение частоты опроса

Измените `POLL_INTERVAL_MS` в `board.h`. Таймер TIM2 автоматически
пересчитает prescaler и period. Остальные зависимые константы
(`POLL_FREQ_HZ`, `LED_TOGGLE_INTERVAL`) вычисляются автоматически.


| POLL_INTERVAL_MS | Частота | Примечание                         |
| ---------------- | ------- | ---------------------------------- |
| 100              | 10 Гц   | Минимальная для отладки            |
| 10               | 100 Гц  |                                    |
| 2                | 500 Гц  | По умолчанию                       |
| 1                | 1 кГц   | Предел для надёжной работы USB CDC |


### Изменение разрешения энкодера

Измените `ENCODER_RESOLUTION_BITS` в `board.h`:

- **17** — для моделей IRS-I34, IRS-I50, IRS-I60
- **18** — для моделей IRS-I70, IRS-I80, IRS-I90

## API драйвера BiSS C

### Инициализация

```c
BiSS_Config cfg = {
    .spi_instance    = SPI1,
    .resolution_bits = ENCODER_RESOLUTION_BITS,
    .de_port         = XCVR_DE_PORT,
    .de_pin          = XCVR_DE_PIN,
    .re_port         = XCVR_RE_PORT,
    .re_pin          = XCVR_RE_PIN,
};
BiSS_Status st = BiSS_Init(&cfg);
```

Настраивает SPI1 (PA5 = SCK, PA6 = MISO) в режиме Master, 0.75 МГц,
CPOL=0 / CPHA=0. Включает трансивер THVD1452: DE = HIGH, RE = LOW.

> **Важно**: тактирование GPIO-портов для DE/RE должно быть включено
> до вызова `BiSS_Init()` (выполняется в `BSP_Init()`).

### Чтение позиции

```c
BiSS_Reading rd;
BiSS_Status st = BiSS_Read(&rd);

if (st == BISS_OK) {
    // rd.position      — позиция (17 или 18 бит)
    // rd.angle_deg     — угол в градусах [0, 360)
    // rd.raw_position  — полные 24 бита с энкодера
    // rd.error         — бит ошибки: 1 = OK, 0 = ошибка
    // rd.warning       — бит предупреждения: 1 = OK, 0 = проблема
}
```

### Текстовое представление статуса

```c
const char *str = BiSS_StatusStr(st);  // "OK", "CRC", "NO_RESP", "SENSOR", "WARN", "SPI"
```

### Коды ошибок


| Код | Константа              | Мнемоника | Описание                                |
| --- | ---------------------- | --------- | --------------------------------------- |
| 0   | `BISS_OK`              | OK        | Данные считаны, CRC совпала             |
| 1   | `BISS_ERR_CRC`         | CRC       | CRC6 не совпала — помеха на линии       |
| 2   | `BISS_ERR_NO_RESPONSE` | NO_RESP   | Энкодер не ответил (нет перехода 1→0→1) |
| 3   | `BISS_ERR_SENSOR`      | SENSOR    | Бит Error = 0 — данные невалидны        |
| 4   | `BISS_ERR_WARNING`     | WARN      | Бит Warning = 0 — проблема с зазором    |
| 5   | `BISS_ERR_SPI`         | SPI       | Ошибка HAL SPI                          |


## Протокол BiSS C

BiSS C — синхронный однонаправленный протокол. Ведущий (STM32) генерирует
тактовый сигнал MA, ведомый (энкодер) отвечает данными на линии SLO.

### Структура кадра

```
Биты на SLO:

│◄─ ACK (4 такта) ─►│ Start │ CDS │◄── SCD (32 бита) ──────────────────►│
│  1  1  1  1        │   0   │  1  │ P23 P22 … P0 │ E │ W │ C5 C4…C0   │
                                    └── 24 бита ──┘       └── CRC6 ──┘
```


| Поле     | Размер  | Описание                                         |
| -------- | ------- | ------------------------------------------------ |
| ACK      | 4 такта | SLO = 1, подтверждение связи                     |
| Start    | 1 бит   | SLO = 0, начало обработки                        |
| CDS      | 1+ бит  | 0 = обработка, 1 = данные готовы                 |
| Position | 24 бита | Абсолютная позиция (MSB first)                   |
| Error    | 1 бит   | 1 = данные валидны / инициализация, 0 = ошибка   |
| Warning  | 1 бит   | 1 = норма, 0 = проблема (зазор / позиция)        |
| CRC6     | 6 бит   | Полином x^6+x^1+x^0, start=0, биты инвертированы |


CRC вычисляется по 26 битам: 24 бита позиции + Error + Warning.

### Параметры интерфейса


| Параметр             | Значение              |
| -------------------- | --------------------- |
| Частота MA           | 0.1 – 5 МГц           |
| Таймаут BiSS (SCD)   | 12.6 – 13.2 мкс       |
| Idle time            | ≥ 100 нс              |
| Макс. частота опроса | 47.5 кГц (при 5 МГц)  |
| Физический уровень   | RS422, 5 В            |
| Время готовности     | 50 мс после включения |


## Устранение неисправностей


| Симптом                      | Возможная причина                          | Решение                                            |
| ---------------------------- | ------------------------------------------ | -------------------------------------------------- |
| COM-порт не появляется       | Нет резистора 1.5 кОм на PA12              | Припаять 1.5 кОм между PA12 и 3.3 В                |
| Постоянно `ERR:NO_RESP`      | Энкодер не подключён / THVD1452 не включён | Проверить подключение и пины DE/RE                 |
| Постоянно `ERR:CRC`          | Помехи на линии, длинный кабель            | Проверить терминацию, укоротить кабель             |
| `ERR:SENSOR` после включения | Энкодер инициализируется                   | Подождать 50+ мс после подачи питания              |
| `[W]` в выводе               | Слишком большой воздушный зазор            | Зазор: 2.8 ± 0.1 мм (2.5 ± 0.2 для I34)            |
| Шум в младших битах позиции  | Нормальное поведение                       | Использовать старшие `ENCODER_RESOLUTION_BITS` бит |
| LED не мигает                | Зависание в инициализации                  | Проверить SPI/USB, подключить отладчик             |
| Пропуски данных в терминале  | USB CDC не успевает                        | Увеличить `POLL_INTERVAL_MS` в `board.h`           |
