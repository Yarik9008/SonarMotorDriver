# Синхронизация с внешним оборудованием — краткое руководство

Стыковка сонара/камеры с платой **SonarMotorDriver** при сканировании сектора.

## Сигналы (3.3 В, общий GND обязателен)

| Сигнал   | Пин  | Кто → кому | Смысл |
| -------- | ---- | ---------- | ----- |
| SYNC_OUT | PB9  | плата → вам | `HIGH` — антенна на точке, можно мерить; `LOW` — плата едет |
| SYNC_IN  | PB12 | вы → плате  | ваш импульс «замер готов»: фронт `LOW→HIGH` (pull-down, ждёт HIGH) |

## Как работает

1. Плата встаёт на точку → **SYNC_OUT = HIGH**.
2. Вы делаете замер и подаёте импульс на **SYNC_IN** (≥ 1 мс).
3. Плата едет к следующей точке → **SYNC_OUT = LOW**. Повтор.

Засчитывается только импульс, поданный при `SYNC_OUT = HIGH`; во время движения — игнорируется.

## Режимы (команда `sync=N`, по умолчанию 0)

| Режим    | Переход к следующей точке | SYNC_IN |
| -------- | ------------------------- | ------- |
| `sync=0` | по таймеру `delay` из `scan=` | не нужен |
| `sync=1` | только по вашему импульсу | обязателен (иначе стоит вечно) |
| `sync=2` | по импульсу **или** `delay` как тайм-ауту | желателен ← **рекомендуется** |

## Запуск

```
sync=2               # режим (ответ ok:sync=2); 0..2, иначе игнор
scan=0,90,0.5,300    # сектор 0..90°, шаг 0.5°, delay=тайм-аут 300 мс
stop                 # завершить
```

## Требования к импульсу SYNC_IN

- длительность ≥ 1 мс, затем возврат в `LOW` ≥ 1 мс (опрос входа 1 кГц);
- уровень 3.3 В (для 5 В — делитель/буфер);
- подавать только при `SYNC_OUT = HIGH`.

## Проверка линии

Команда `sync` → `sync=1 in=0 out=1 n=42` (режим, уровень SYNC_IN, уровень SYNC_OUT, счётчик принятых импульсов). Подайте импульсы — `n` должно вырасти на их число.
